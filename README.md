# Classy Sorry Site

A warm, friendly three-page apology experience with an elegant entrance, a
cute teddy holding flowers, and a simple final “I’m truly sorry” page.

## Live site

[Open the GitHub Pages site](https://lusifer733866.github.io/classy-sorry-site/)

## Pages

- Page 1: a gentle entrance
- Page 2: a teddy bear with flowers
- Page 3: a clean, minimal apology headline

The Next/Vinext source lives in `app/`. The static GitHub Pages build lives in
`docs/` and uses relative links so all three pages work under the repository
subpath.

## Local development

```bash
npm install
npm run dev
```
